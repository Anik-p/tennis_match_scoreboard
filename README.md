# 🎾 Теннисное Табло (tennis_match_scoreboard)

Веб-приложение для подсчета счета в теннисного матча. Проект реализован на чистом Python без использования веб-фреймворков (Django/FastAPI).

## 🚀 Ключевые особенности и архитектура

*   **Кастомный HTTP-сервер:** Написан на базе `http.server`. Реализован собственный роутинг эндпоинтов, ручная отдача статических файлов и кастомный рендеринг страниц ошибок.
*   **Архитектурные паттерны:** Применен подход **Data Mapper / Repository** и паттерн **Unit of Work (UOW)** для изоляции бизнес-логики (`MatchService`) от деталей реализации ORM.
*   **База данных:** Использование `SQLAlchemy 2.0` (с драйвером `PyMySQL`) для работы с MySQL. Миграции базы данных полностью автоматизированы с помощью **Alembic**.


## 🛠️ Технологический стек

*   **Language:** Python 3.12+
*   **Database & ORM:** MySQL 8.0, SQLAlchemy 2.0, Alembic
*   **Templates:** Jinja2
*   **DevOps / Infrastructure:** Docker, Docker Compose
*   **Testing:** Pytest

## 📦 Запуск через Docker

Проект полностью контейнеризирован. Для запуска вам понадобятся только Docker и Docker Compose.

### 1. Настройка окружения
Создайте файл `.env` в корневом каталоге проекта и заполните его по следующему шаблону:

```env
MYSQL_USER=root
MYSQL_PASS=your_password
MYSQL_HOST=your_host
MYSQL_NAME=your_name
MYSQL_PORT=3306
API_HOST=localhost
API_PORT=8000
```

### 2. Запуск приложения
Выполните команду в терминале:

```bash
docker compose up --build
```

**Что произойдет автоматически:**
1. Развернется и инициализируется контейнер с базой данных MySQL.
2. Сработает встроенный `healthcheck`: веб-сервер дождется полной готовности БД.
3. Накатятся все миграции Alembic.
4. Запустится веб-сервер на порту `8000`.

Приложение будет доступно в браузере по адресу: **`http://127.0.0.1:8000/`**

## 🧪 Тестирование

Бизнес-логика подсчета теннисных очков (геймы, сеты, тай-брейки) покрыта юнит-тестами.

Для запуска тестов (локально) выполните:

```bash
py -m pytest
```
